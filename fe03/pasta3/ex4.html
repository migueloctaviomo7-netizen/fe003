Perguntas frequentes

Qual é a diferença entre HTML e CSS?

HTML estrutura o conteúdo da página, enquanto o CSS é responsável pelas cores, fontes e posicionamento.

O que são elementos vazios?

São elementos que não possuem tag de fechamento nem conteúdo interno, como img, hr e br.
